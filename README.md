# 🎨 HTML & CSS Exercises

Este repositório contém exercícios práticos de **HTML e CSS**, com foco na construção de interfaces e no desenvolvimento de fundamentos do front-end.

---

## 🚀 Tecnologias

- HTML5
- CSS3

---

## 📂 Estrutura

Os exercícios estão organizados por tipo e nível de dificuldade:

- `basic/` → fundamentos de HTML e CSS  
- `layout/` → estruturação de páginas  
- `components/` → criação de elementos reutilizáveis  

---

## 🎯 Objetivo

Desenvolver habilidades em:

- Estruturação semântica de páginas  
- Estilização com CSS  
- Responsividade  
- Organização de layout  

---

## 📌 Observações

Os exercícios representam minha evolução no aprendizado de front-end e são um reflexo da minha base de estudos.
